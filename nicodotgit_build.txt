=============================================================================
UV-K5 CUSTOM FIRMWARE - "nicodotgit" HYBRID BUILD
Base: F4HWN (Fork)
Target: DP32G030 (60KB Flash Limit)
Free Space Remaining: 36 Bytes
=============================================================================

This build is engineered to maximize hardware utility on a strict 60KB limit, 
combining the active Spectrum Analyzer and Broadcast FM Radio while retaining 
vital quality-of-life UI upgrades (Custom Menus, Bold Fonts).

-----------------------------------------------------------------------------
[ENABLED FEATURES]
-----------------------------------------------------------------------------
Core Modules:
* ENABLE_SPECTRUM=1       : Activates the live visual bandscope/analyzer.
* ENABLE_FMRADIO=1        : Activates the BK1080 hardware Broadcast FM receiver.
* ENABLE_AM_FIX=1         : Software AGC loop to prevent AM Airband distortion.

Quality of Life & UI:
* ENABLE_CUSTOM_MENU_LAYOUT=1 : Organizes the settings in a cleaner layout.
* ENABLE_SMALL_BOLD=1     : Replaces thin UI text with a highly legible bold font.
* ENABLE_BIG_FREQ=1       : Renders the active frequency with massive numbers.
* ENABLE_RSSI_BAR=1       : Displays a live signal strength (S-meter) bar graph.
* ENABLE_FEAT_F4HWN_CTR=1 : Adds LCD contrast adjustment to the menu.

Radio Behaviors:
* ENABLE_COPY_CHAN_TO_VFO=1 : Shortcut to copy a memory channel's attributes to VFO.
* ENABLE_FEAT_F4HWN_RESUME_STATE=1 : Remembers exact VFO/Menu position across reboots.

Hardware Mods:
* INVERTED SCREEN         : Baked directly into `st7565.c` to enable
                            Dark Mode without wasting OS menu memory.
* FLASHLIGHT BYPASS       : Flashlight UI is disabled, but the LED can still be 
                            triggered via the PTT-hold pre-boot hardware state.

-----------------------------------------------------------------------------
[DISABLED FEATURES]
-----------------------------------------------------------------------------
Cosmetic & Minor UI:
* ENABLE_AUDIO_BAR=0      : No live microphone level meter during transmission.
* ENABLE_SHOW_CHARGE_LEVEL=0 : Standard battery icon instead of precise voltage/%.
* ENABLE_KEEP_MEM_NAME=0  : Channel name does not persist when jumping to VFO mode.
* ENABLE_FEAT_F4HWN_VOL=0 : No visual volume slider pop-up.
* ENABLE_FEAT_F4HWN_INV=0 : Dark mode menu toggle removed (hardcoded instead).
* ENABLE_PWRON_PASSWORD=0 : No PIN code lock screen on boot.
* ENABLE_FEAT_F4HWN_SLEEP=0 : No auto-power-off timer.

Heavy Modules:
* ENABLE_DTMF_CALLING=0   : Removes selective paging, contact IDs, and DTMF decoding.
* ENABLE_FEAT_F4HWN_SCREENSHOT=0 : Removes UART screen-dump functionality.
* ENABLE_VOX=0            : Removes Voice Operated Transmit audio processing.
* ENABLE_AIRCOPY=0        : Removes wireless radio-to-radio cloning.

Gimmicks & Regional Lists:
* ENABLE_FEAT_F4HWN_GAME=0 : No Snake/Pong minigames.
* ENABLE_NOAA=0           : No North American weather bands.
* ENABLE_FEAT_F4HWN_PMR=0 : No European PMR446 hardcoded channels.
* ENABLE_FEAT_F4HWN_GMRS_FRS_MURS=0 : No US FRS/GMRS hardcoded channels.
* ENABLE_FEAT_F4HWN_RESCUE_OPS=0 : No French rescue channels.
* ENABLE_TX1750=0         : No European 1750Hz repeater wake-up bursts.
* ENABLE_ALARM=0          : No emergency panic siren.

-----------------------------------------------------------------------------

-----------------------------------------------------------------------------
